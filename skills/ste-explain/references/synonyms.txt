# 同义词组：一行一组，组内用 / 分隔。同一份文档里同一组出现两个以上不同的词时，ste_check.py 报出。
# ! 开头的行是例外词：含该复合词的位置不计入组内任何词的出现。
# 入组标准：组内各词在工程文档里指同一个动作或同一个东西，互换不改变意思。
# 匹配是子串匹配，单字词与会大量出现在别的词里的字不入组。

# 动作：检查与判定
检查/校验
比较/对比/比对
确保/保证
# 校验 / 验证 / 确认 在工程语境里是三个动作（校验数据、验证方式、向人确认），验证与确认不入组。

# 动作：增删改
创建/新建/建立
删除/移除/清除
修改/更改
替换/置换
覆盖/覆写
调整/调节
设置/设定

# 动作：读写与传输
获取/读取/拿到
加载/载入
保存/储存
发送/发出
推送/推上
拉取/拉下
显示/展示/呈现
查找/搜索/检索
列出/列举

# 动作：运行与控制
启动/拉起/开启
停止/终止
重启/重新启动
重试/重新尝试
重新运行/重新执行
运行/执行
等待/等候
跳过/略过
允许/容许
禁止/不允许
使用/采用/利用
合并/合入
回退/回滚/还原
# 更新 / 刷新、编译 / 构建、安装 / 部署、中止 / 中断 / 取消、恢复 / 还原 各是不同动作，不入组。

# 动作：因果与变化
导致/引起/造成
提升/提高/改善
降低/减少
包含/包括/含有

# 名词

# 问题 / 缺陷 / 故障 / 异常、方法 / 方式 / 做法、接口 / 界面 各有所指，不入组。

# 连接词与情态
