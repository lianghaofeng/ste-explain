# 规则表

本文件是 SKILL.md 规则的完整版：每条规则的编号、STE 原规则的出处、对中文是否成立、取舍理由。SKILL.md 只列规则正文，查理由到这里。

## 1. 80% 刻度的定义

Karpathy 2026-10-02 的说法是「80% of the way to ASD-STE100」。本 skill 把它定义为：九条结构规则全部执行，词汇不锁定。不锁定的意思是允许领域术语、英文术语、常用缩略语，以及「因为 / 所以」这类说理连接词。100% 在此之上追加五条，见第 3 节。

## 2. 80% 规则（R1 到 R9）

| 编号 | 规则 | STE 原规则 | 对中文 | 处理 |
| --- | --- | --- | --- | --- |
| R1 | 一句只说一件事 | 一句一条指令；描述句不叠多个事实 | 成立 | 执行 |
| R2 | 一句不超过 N 字 | 指令 20 词、描述 25 词 | 成立，单位换成字 | 执行。N 由 `ste_check.py` 的默认值定义，当前 45 |
| R3 | 主动语态，说清谁做了什么 | 指令用主动；描述句只在执行者不明或无关时用被动 | 成立 | 执行 |
| R4 | 用动词，不用名词化 | Rule 3.7：用动词描述动作 | 成立 | 执行。写「检查日志」，不写「对日志进行检查」 |
| R5 | 一词一义，同一动作全程同一个词 | 词典每词一义；不轮换同义词 | 成立 | 执行。`ste_check.py` 按 `synonyms.txt` 检查 |
| R6 | 用具体数字和场景解释，不打比方 | STE 无直接对应；来自读者设定 | 成立 | 执行 |
| R7 | 三步以上用编号清单，并列项用清单，比较用表格 | 序列、条件用竖排清单 | 成立 | 执行 |
| R8 | 一段一个主题，不超过六句，重点句放段首 | 一段一主题，最多六句 | 成立 | 执行 |
| R9 | 术语首次出现给一句定义；没有统一译法的保留英文 | 允许项目词表，术语要定义 | 成立 | 执行 |

## 3. 100% 追加（S1 到 S5）

用户说「严格」「100%」「完整 STE」，或文本是操作步骤、安全说明时启用。

| 编号 | 规则 | STE 原规则 |
| --- | --- | --- |
| S1 | 每条指令单独成句，用祈使句 | 指令用祈使句 |
| S2 | 不省略主语 | 不省略句子成分 |
| S3 | 不用缩略语，首次出现写全称 | 词典内无该缩略语则不用 |
| S4 | 安全类内容先写后果，再写动作 | 安全指令以警告或条件开头 |
| S5 | 每句都能对应到一条事实；推断单独成句并标注「推断」 | STE 无直接对应；来自读者设定 |

## 4. 守则（G1 到 G6）

高于所有规则。规则与守则冲突时守则赢。

| 编号 | 守则 | 为什么高于规则 |
| --- | --- | --- |
| G1 | 保留原文的不确定程度。「可能失败」不能变成「失败」，「有时」不能变成「总是」 | 句长上限最容易逼人删掉「可能」。删掉之后句子更短，但说的是另一件事 |
| G2 | 不新增原文没有的原因、频率、机制 | 补一个原因会让改写读起来更顺，但那是新的断言 |
| G3 | 代码、命令、标识符、报错原文不改 | 读者要照着执行或搜索 |
| G4 | 事实与推断分开标注。事实给文件行号或命令与输出摘录，推断说明「未验证，跑 X 可确认」 | 读者据此决定信多少 |
| G5 | 清楚即止，不追求最短。为缩短而丢掉条件、例外、范围限定时，写两句 | 目标是没有歧义，不是字数 |
| G6 | 已经合规的文本只回「已合规」，原文一字不动：不拆句、不补术语定义、不换词 | 改动本身有成本，也有引入错误的机会。R9 的术语定义只给不合规文本的改写加，不给合规文本加 |

## 5. 英文输入专属（E1 到 E3）

输入是英文时，R1 到 R9 与守则照用，另加三条。

| 编号 | 规则 | 例 |
| --- | --- | --- |
| E1 | 不用 phrasal verb | 写 start，不写 spin up；写 remove，不写 take off |
| E2 | 只用简单时态；带不确定程度的 may have 保留 | 写 we received，不写 we have received；may have failed 保留（G1） |
| E3 | 不用分号 | 拆成两句 |

## 6. 不采用的 STE 规则

| STE 规则 | 为什么不采用 |
| --- | --- |
| 禁 phrasal verb、只用简单时态、不省冠词、禁分号 | 英文语法专属，中文没有对应物；只在英文输入时作为 E1 到 E3 生效 |
| 官方词典约 900 个核准词与约 1200 个不建议用的词 | 是英文；ASD 不允许转载。本 skill 用 R5 与 R9 替代：同一动作同一个词，术语首现定义 |
| 名词簇不超过三个词 | 中文对应物是长定语，属于用词与翻译腔层面，交给中文写作 skill |

## 7. 图

三个以上相互作用的部件，或有顺序、状态变化，加一张 mermaid 图。一图一事，节点超过十二个拆成两张，箭头带动词，图里的名字和正文一致，图下方一句话告诉读者从哪看起。图中文字遵守 R1 到 R9。用户点名要图就画，点名不要就不画。
